The Scripting DSL

A production is a plain-text script of scene blocks and at blocks. The parser turns it into timeline events, camera rigs, animations, scene-graph nodes and post presets — no C++ involved.

Shape of a script

A script is a list of declarations: an optional demo header, any number of scene blocks, and any number of top-level at blocks. Commands are line-oriented — ; or a newline separates them, { } group options. Comments are //, #, or /* ... */.

data/demo.nsdnsd
// header: the show title, tempo and total length
demo "NULL SECTOR DEMO ENGINE" {
    bpm 216
    duration 125
}

// a scene: setup commands run when the scene activates
scene Intro {
    bars 12  intensity 0.12  chapter 0
    title "Awakening"
    camera IntroCam { rig drift; pos (0,0,2.4); fov (50,58); amp 1.6; freq 0.14 }
    show intro
    play music
    fade in 2
    at 4 { anim introBloom post.bloom smooth { 0 1.2; 3 2.4; 6 1.5 } }
    at 11 { transition fade 1 }
}

// top-level at: absolute show time, fires once
at 0    { show Intro;    marker Awakening }
at 13.3 { show Cathedral; marker Nave }
at 64.4 { show Shadertoy; marker Imported }

Blocks

BlockPurpose
demo "TITLE" { ... }Show metadata: bpm (tempo, beats-per-minute), duration (total seconds; otherwise inferred from scenes).
scene Name { ... }A section of the show: metadata pairs (bars, intensity, chapter, title) plus setup commands and scene-relative at sub-blocks (times count from scene start).
at TIME { ... }An absolute-time event on the show timeline; its commands fire when the clock crosses TIME.

Scene metadata

PairMeaning
bars NSection length in bars (4 beats @ bpm). Drives section scheduling.
intensity X0..1 energy level — available to effects and the music-reactive post chain.
chapter NAct grouping (used by jump-to-section).
title "Text"Display title for the section.

Time formats

Any of these are valid wherever a time is expected — at block start, anim keyframes, marker:

Commands

Commands appear inside at blocks, inside scene setup, or both. Scalar options accept a plain number or a (base, target) ramp that eases from base to target across the scene's build-up window.

animanim camOrbit camera.pos smooth { 0 (0,1.2,7); 4 (2.4,1.6,5) }Define & play a keyframed animation (see Animation).

Note

Unknown commands or malformed times raise a ScriptError with a message naming the file and token — the unit tests deliberately feed the shipped demo.nsd through the parser so data regressions surface in CI, not on stage.

Parsing model

The parser (src/framework/script/scriptparser.{hpp,cpp}) produces a typed AST: Script → SceneDef + ScriptBlock + Cmd. The ScriptEngine (src/framework/script/scriptengine.cpp) then:

  • compiles every at block into a timeline event, sorted by time;
  • builds a section schedule from scene lengths and activation times;
  • keeps scene setup commands as activation bundles the director fires on section entry.
