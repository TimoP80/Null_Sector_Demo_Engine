GHOST IN THE MACHINE

A data-driven demo engine. The whole show — scenes, cameras, effects, animations, post processing, 3D models and imported Shadertoy shaders — lives in external files. The engine is never recompiled to make a new demo.

data/demo.nsd

The idea in one screen

A demoscene production is a timeline: scenes fire at exact times, cameras move on rails, effects start and stop, and the music drives the visuals. This engine turns that timeline into a language, and everything else into files.

~

Script, don't code

at 26.7 { show Neuralnet; marker Synapse } — a production is a plain-text script. No effect is hardcoded in the renderer.

◍

Everything is data

Scenes, timelines, materials, post presets, camera rigs and assets are JSON or GLSL on disk, loaded at runtime and hot-reloaded while it plays.

▶

Plays to the music

The audio engine analyses the track — bass, mid, treble, kick, beat, BPM — and feeds the values to shaders as uniforms.

⌘

Extensible by plugin

New effects register themselves through a factory registry; plugins can be dropped in as shared libraries without touching the engine.

Architecture

Four layers. The shell owns the window and the frame loop; the director turns data into events; the framework is a GL-free library of authoring systems; the engine is the raw GL layer. Only the bottom two touch OpenGL.

Quick start

The project builds with CMake; GLFW is fetched automatically when not found. The framework core is GL-free and compiles anywhere.

terminalbash
# build everything (framework + tests + app)
cmake -S . -B build -DNS_BUILD_APP=ON -DNS_BUILD_TESTS=ON
cmake --build build --config Release --target ns_demo ns_fw_tests

# run the framework test suite (no GL needed)
./build/Release/ns_fw_tests.exe

# run the show (drop a WAV/MP3 next to it to add music; without one it runs silent)
./build/Release/ns_demo.exe --windowed
Live

While the show runs, edit data/demo.nsd or any shader, texture or model it references — press F2 to reload the script, and shaders/textures/models reload automatically. No restart, no recompile.
