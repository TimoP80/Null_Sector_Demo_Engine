09 Rendering · Post FX

Post-Processing Stack

A configurable chain of stackable passes, built from data instead of being hardcoded. Passes ping-pong between two RGBA16F targets; the whole chain is a JSON preset or a one-line script command.

Available passes

PassExample paramsNotes
doffocus, apertureDepth of field — uses the depth packed in the scene alpha.
bloomthreshold, intensityHDR bloom; extract → blur (two-pass separable) → compose.
chromaticamountChromatic aberration.
vignetteamount, curveCorner darkening.
grainamountFilm grain (time-seeded).
scanlinesamountCRT-style scanlines.
pixelateamountPixelation.
gradetonemap, saturation, contrast, exposureColor grading + optional tonemap. Must be before fxaa.
fogdensity, colorDepth fog from the packed alpha.
fxaa—Fast anti-aliasing — always last.
copy—Lossless HDR copy.

Preset format

A preset is a JSON file in data/post/ (asset kind post): an ordered passes array, each pass a name + params. Depth-dependent passes (dof, fog) must come first; fxaa must come last because it does not preserve the depth alpha.

data/post/cinematic.jsonjson
{
  "name": "cinematic",
  "passes": [
    { "name": "bloom",     "threshold": 1.0, "intensity": 1.3 },
    { "name": "grade",     "tonemap": true, "saturation": 1.06,
                           "contrast": 1.04, "exposure": 1.0 },
    { "name": "vignette",  "amount": 0.45, "curve": 2.2 },
    { "name": "fxaa" }
  ]
}

Bundled presets

PresetLook

cleanLight touch for the 3D asset pipeline scene.

In the script

Three ways to drive the chain — preset, the legacy music-reactive chain, or an inline override:

data/demo.nsdnsd
post preset cinematic        // load data/post/cinematic.json
post legacy                  // the original music-reactive chain (bloom+CRT+flash)
post { exposure 1.15 }       // inline params override

// and animate it:
at 2 { anim netExposure post.exposure smooth { 0 0.9; 5 1.15; 10 1.0 } }

Music-reactive chain

A PostCtx rides alongside each frame: time, delta, camera (for DOF/fog), motion, plus the audio-driven bloomMul, glitch, exposure, heat and kick — mapped onto bloom intensity, grade exposure and chromatic amount. Preset-driven stacks slam with the drum automatically.

Tip

Post params are animation targets too (post.bloom, post.exposure, post.glitch), so keyframes can shape the look mid-scene — exactly how the Ghost scene swells its bloom at the formation.
