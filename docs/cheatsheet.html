One-Page Cheat Sheet

The whole DSL on one page. Every syntax form, time format, command, rig, interpolator and uniform name — for when you know what to write but can't remember how.

Minimal demo

data/my_demo.nsdnsd
demo "MY DEMO" {
    bpm 128
    duration 60
}

scene Intro {
    bars 8   intensity 0.5  chapter 0
    title "Cold Open"
    camera Cam1 { rig static; pos (0,0,4); target (0,0,0); fov 60 }
    show myeffect
    play music
    fade in 2
    at 7 { transition fade 1 }
}

at 0    { show Intro;     marker ColdOpen }
at 15.2 { show SceneTwo;  marker B }

Time formats

Anywhere a time is expected: at, anim keys, marker, jump.

WriteMeans
12.5Seconds
1:05.0Clock time (mm:ss.ms)
66.667sSeconds, explicit
beat 128Beat number @ bpm
bar 32Bar number (4 beats)

Bar/beat resolve against the demo { bpm } header.
