Animation System

Keyframe animation for anything addressable by a property path — cameras, scene nodes, lights, effects, post parameters and text. Built from script blocks or JSON, played and stopped by timeline events, sampled per frame.

Property paths

An animation has one or more channels, each targeting target.property. The target selects what, the property selects which value:

TargetPropertiesScript example
camerafov, pos, targetcamera.pos, camera.fov
node:<name>pos, rot, scale, color, opacitynode:gem.euler, node:caption.opacity
light:<name>intensity, colorlight:sun.intensity
effect:<name>uniform:<uName> — any shader uniformeffect:cathedral.uniform:uMode
postexposure, bloom, glitch, …post.exposure, post.bloom
text:<name> / particle:<name>values / parameterstext:caption.opacity

Script syntax

Keyframes are time value [interp] rows; a bare interp after the target sets the channel default. Multiple channels can share one anim block.

data/demo.nsd — the Asset Pipeline scenensd
// one channel, scalar keys, default interp given per key
at 4 { anim pillGlow effect:cathedral.uniform:uMode smooth {
    0 0; 3 0.6; 6 0 } }

// keyframed camera orbit — vector keys, per-key interpolators
at 1 { anim camOrbit camera.pos smooth {
    0 (0,1.2,7); 4 (2.4,1.6,5); 8 (0,2.0,3.4);
    10 (-2.4,1.6,5); 12 (0,1.2,7) } }

// node transforms — pos, euler rotation, opacity
at 1 { anim gemSpin node:gem.euler linear { 0 (0,0,0); 9 (0,360,0) } }
at 1 { anim gridBob node:terrain.pos bounce { 0 (0,-0.5,0); 4 (0,-0.35,0); 8 (0,-0.5,0) } }
at 1 { anim captionFade node:caption.opacity elastic { 0 0; 2 1; 8 1 } }

Interpolators

Nine interpolators, each a named easing the keyframe rows (or the channel default) can request. The same functions back the camera-rig build-up ramps.

NameCharacterUse it for
linearConstant velocitySpin, drift, sweep
smoothSmoothstep, ease in & outThe default for organic motion
cubicCatmull-Rom spline through keysCamera paths, flowing curves
bezierCubic Bézier with neighbour-derived handlesFull control, custom curves
ease-inAccelerates from restEntrances, fall-away exits
ease-outDecelerates to restLandings, arrivals
ease-in-outSlow both endsIdle loops, camera holds
bounceOvershoots and reboundsWeight, impact, drop-in UI
elasticSpringy overshoot wobbleAttention-grabbing entrances

Runtime model

  • Library — named Animation objects with channels; add/get.
  • Playback — play(name, startT, speed), stop, seek, isPlaying, plus stopTarget to cut every animation affecting one target.
  • Sampling — update(dt) advances active animations and appends AnimSamples; the director drains them and applies target.property = value each frame.
  • Evaluation — the static sampleChannel/interpValue helpers are pure and reusable; out-of-range times clamp to the nearest key.
Note

Out-of-range times clamp to the nearest key — so a keyframe at 0 and 9 with a hold means the value stays put after the last key. Add a final key to "park" a value.
