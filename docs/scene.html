Scene Graph

A proper node hierarchy with local and world transforms, visibility, tags and layers. Ten node types carry the payloads the renderers read — the graph itself is GL-free and serializes to JSON.

Core features

⌘

Hierarchy

Parent/child trees; world matrices recompute lazily down the dirty chain.

◈

Transforms

Local position, quaternion rotation, scale (or euler degrees), full TRS matrices.

◉

Visibility

visible + enabled; enabled propagates to children, isActive() checks the whole ancestor chain.

◫

Tags & layers

Tag any node and query across the tree; assign layers for selective rendering.

Node types

Each node carries a payload variant. The engine-side renderers read these; the director builds them from script commands or scene JSON.

TypePayloadKey fields
empty—Grouping / transform parent.
cameraCamDatafov, nearP, farP, target, rig name.
lightLightDatatype (directional | point | spot), color, intensity, range, angle, castShadow.
meshMeshDatamodel (OBJ path), material (name), scale, lit.
particlesParticleDatavertex/fragment shaders, count, renderScale.
quadQuadDatafrag shader, handoff (in-scene transition), renderScale, mode.
sprite / imageSpriteDatatex, color, opacity, size (world units). The image DSL command also supports fade, crossfade, zoom and slide entrance transitions.
textTextDatatext, sizePx, font, style (terminal | holo | glitch | neon | scan | dissolve | chrome | outline), opacity, align.
postPostDatapreset — post preset name.
timelineTimelineDatafile — a timeline JSON to attach.

Script commands

Scene-graph nodes are built directly in the DSL — the Asset Pipeline scene of the bundled demo builds an entire 3D set in five commands:

data/demo.nsd — scene Modelnsd
scene Model {
    bars 10  intensity 0.5  chapter 2
    title "Asset Pipeline"
    camera Reticle { rig static; pos (0,1.2,7); target (0,0.5,0); fov 52 }
    shader dataviz_bg.frag
    post preset clean

    load material chrome
    load material neon
    load model terrain.obj
    load model gem.obj

    mesh terrain { model terrain.obj; material chrome; pos (0,-0.5,0) }
    mesh gem    { model gem.obj;    material neon;  pos (2.2,1.4,0); scale (0.8,0.8,0.8) }

    light sun  { type directional; color (1,0.92,0.78); intensity 2.0 }
    light fill { type point;       color (0.4,0.6,1);  intensity 6; range 14 }

    sprite halo { tex ghost_logo.png; pos (0,1.9,-4); size (5,2.5,1); opacity 0.55 }
    text caption { text "3D // PBR // OBJ IMPORT"; pos (0,0.55,0); size 26; style neon }

    at 1 { anim gemSpin node:gem.euler linear { 0 (0,0,0); 9 (0,360,0) } }
    at 1 { anim gridBob node:terrain.pos bounce { 0 (0,-0.5,0); 4 (0,-0.35,0); 8 (0,-0.5,0) } }
    at 9 { transition fade 1 }
}

JSON scene format

The whole graph serializes to JSON (data/scenes/*.json, asset kind scene) — hierarchy, transforms, tags and payloads all round-trip. Excerpt from the bundled lightbox.json:

data/scenes/lightbox.jsonjson
{
  "name": "world",
  "type": "empty",
  "pos": [0, 0, 0],
  "children": [
    {
      "name": "lightrig",
      "type": "empty",
      "pos": [0, 2, 0],
      "children": [
        { "name": "sun", "type": "light", "pos": [0, 8, 6],
          "light": { "type": "directional", "color": [1.0, 0.92, 0.78],
                     "intensity": 2.0, "range": 10.0, "angle": 45.0,
                     "shadow": false } },
        { "name": "fill", "type": "light", "pos": [4, 3, -4],
          "light": { "type": "point", "color": [0.4, 0.6, 1.0],
                     "intensity": 6.0, "range": 14.0 } }
      ]
    },
    { "name": "terrain", "type": "mesh", "pos": [0, -0.5, 0],
      "tags": ["ground", "lit"],
      "mesh": { "model": "terrain.obj", "material": "chrome", "scale": 1.0, "lit": true } },
    { "name": "caption", "type": "text", "pos": [0, 2.3, 0],
      "text": { "text": "3D // PBR // OBJ IMPORT", "size": 26,
                "style": "neon", "opacity": 1.0 } }
  ]
}
Tip

Script mesh/sprite/text/light commands are the fast path for one-off nodes; scene JSON is the right tool for reusable, artist-authored sets.

API surface

  • SceneGraph::addNode(name, type, payload, parent), find(name) (DFS), findTag(tag), nodesOf(type, activeOnly).
  • SceneNode::setPos/setRot/setScale/setEuler, computeLocal(), updateWorld(parentDirty), isActive().
  • SceneGraph::update() recomputes all world matrices once per frame; walk(fn) visits depth-first, parents first.
