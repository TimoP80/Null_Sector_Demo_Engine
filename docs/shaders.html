07 Rendering · Shaders

Shader Manager

A modern shader layer: automatic compilation, #include support with dependency tracking, caching, reflection and uniform binding — plus hot reload that recompiles any shader when it (or an included file) changes on disk.

Features

⚙

Automatic compilation

Vertex/fragment pairs compile and link on demand; failures log the stage, file and source line instead of dying.

#

Include support

#include "common.glsl" resolves relative to the shader dir; the dependency graph is tracked for reloads.

▣

Caching

Programs are cached by name and shared — effects, post passes and sprites never recompile identical sources.

⟲

Hot reload

The file watcher notices changes and recompiles affected programs live; version counters let renderers rebind.

◌

Reflection

Active uniforms are queried after link — the director uses this to bind uBass, uTime, matrices, and per-effect uniform:<name> animation targets.

⛓

Uniform binding

Typed setters (set1f, setVec, setMat4, set1i) driven by the reflected uniform table — unknown uniforms are safely skipped.

Shader layout

Engine shaders live in shaders/; effect shaders are GLSL on disk, loaded by the asset manager and compiled by the manager. A shared header carries the common uniforms:

shaders/common.glsl (excerpt)glsl
#ifndef NULLSECTOR_COMMON_GLSL
#define NULLSECTOR_COMMON_GLSL

uniform float uTime;
uniform vec2  uResolution;
uniform float uBass, uMid, uTreble, uKick, uVolume, uBeat; // audio feeds
uniform mat4  uView, uProj, uVpInv;

#endif

Audio-reactive uniforms

The audio analyser publishes bass / mid / treble / kick / beat / volume every frame; the director pushes them into every active effect under the uBass … uBeat names. Any shader that declares them becomes music-reactive with zero wiring.

example — pulse with the kickglsl
vec3 col = baseColor * (1.0 + 0.6 * uKick);   // slam on the drum
col *= 0.7 + 0.6 * uBass;                      // breathe with the bass

Validation

Every engine shader stage — plus the app's forward-lit lit.vert + lit.frag program — is compiled at startup with --check-shaders (68/68 engine stages pass in the shipped tree). Shaders referenced only by data are compiled when the effect first shows — and recompiled automatically on hot reload.
